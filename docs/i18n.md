# Internationalization (i18n)

The SDK includes built-in translations for English (`en`) and Traditional Chinese (`zh-TW`).

## Basic Usage

Translations are handled automatically by `FerretProvider`:

```svelte
<!-- All child components will use Traditional Chinese -->
<FerretProvider config={config} locale="zh-TW">
  <LoginFlow />
</FerretProvider>
```

## Programmatic Usage

```ts
import { createT } from '@ferret/sdk-svelte';

const t = createT('zh-TW');
t('action.login');                                    // → "登入"
t('error.field.password_too_short', { min: 10 });     // → "密碼至少 10 個字元"
```

## Accessing in Components

Inside any component wrapped by `FerretProvider`:

```svelte
<script lang="ts">
  import { getFerretT } from '@ferret/sdk-svelte';
  const t = getFerretT();
</script>

<p>{t('action.login')}</p>
```

## Override Translations

Pass `translations` to `FerretProvider` to override specific keys:

```svelte
<FerretProvider
  config={config}
  locale="en"
  translations={{
    'action.login': 'Sign In',
    'action.register': 'Create Account'
  }}
>
  <LoginFlow />
</FerretProvider>
```

## Register a Custom Locale

```ts
import { registerLocale } from '@ferret/sdk-svelte';

registerLocale('ja', {
  'action.login': 'ログイン',
  'action.register': 'サインアップ',
  'action.logout': 'ログアウト',
  // ... add all keys you need
});
```

Then use it:

```svelte
<FerretProvider config={config} locale="ja">
  <LoginFlow />
</FerretProvider>
```

Missing keys fall back to English.

## Parameter Interpolation

Use `{{param}}` in translation values:

```ts
registerLocale('ja', {
  'error.field.password_too_short': 'パスワードは{{min}}文字以上にしてください。'
});

const t = createT('ja');
t('error.field.password_too_short', { min: 10 });
// → "パスワードは10文字以上にしてください。"
```

## Fallback Chain

1. Overrides passed to `createT(locale, overrides)`
2. Registered locale translations
3. English (`en`) translations
4. The key itself (returned as-is if no translation found)
